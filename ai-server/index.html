🤖 PMApp AI 助理后端

这是一个 Node.js 服务，为 PWA 里的 AI 浮窗「小P」提供自然语言问答接口，数据全部来自 Supabase 中已存在的模块。

运行方式

cd ai-server
npm install
cp .env.example .env      # 编辑并填入 LLM_API_KEY（DeepSeek 免费 key）
npm start

接口

  • POST /api/chat — 提问。body: {"messages":[{"role":"user","content":"越南工厂本周有哪些延误的生产子计划？"}]}
  • GET /api/health — 健康检查

暴露给 PWA

启动后，在 CloudStudio 点击「端口预览」→ 选择端口 3000 → 复制生成的公网 URL， 打开 PWA 右下角 💬 浮窗 → 点 ⚙️ → 填入该 URL 并保存，即可开始提问。
